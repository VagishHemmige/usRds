[The Assessment of Infection Risk in Patients with Vitiligo Undergoing Dialysis for End-Stage Renal Disease: A Retrospective Cohort Study.](https://pmc.ncbi.nlm.nih.gov/articles/PMC10821439/) · 2024 · doi:10.3390/pathogens13010094

Reading: **MT**, 2026-11-15. Main-text reading; figures as images and supplements not inspected; tables not comprehensively checked unless stated.

- **Role / population / unit:** dialysis initiators 2004–2019, vitiligo diagnoses and first infection; individual claims-defined exposure/outcome. [reported Methods]
- **Sources:** CMS-2728, patient file and hospital/detailed/physician claims. Vitiligo uses 709.01, L80 and eyelid-vitiligo codes. [reported Methods]
- **Data needs:** retain diagnosis dates and code versions; distinguish separate infection endpoints and censoring times. Exposure is diagnosed after dialysis begins. [reported Methods]
- **Pitfalls:** temporal ordering relative to infection is insufficiently specified. A logistic model with log-person-time offset is not automatically a rate model. Claims completeness cannot be inferred from the paper's assertion that all dialysis patients automatically enroll in Medicare. Several printed ancillary codes contain questionable formatting; do not paste them into a code list. [reported Methods; inference]
- **Locators:** complete main text; tables unread. Results contains conflicting racial-association wording. Sparse PD representation and vitiligo underascertainment limit inference. Useful for identifying phenotype/time-origin checks, not as an endorsed causal modeling template.
