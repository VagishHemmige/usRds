### PMC9171697

[Hydralazine-Isosorbide Dinitrate Use in Patients With End-Stage Kidney Disease on Dialysis.](https://pmc.ncbi.nlm.nih.gov/articles/PMC9171697/) · 2022 · doi:10.1016/j.ekir.2022.03.032

Reading: **MT**, 2026-11-15. Main-text reading; figures as images and supplements not inspected; tables not comprehensively checked unless stated.

- **Role / population / unit:** USRDS dialysis patients with heart failure, 2011–2016; H-ISDN users versus nonusers, person/follow-up interval. [reported Methods]
- **Sources:** A/B claims, Part D fills, hospitalization and death/cause data. Require ≥6 months A/B during the preceding year and continuous D for ≥6 months. [reported Methods]
- **Data needs:** user entry is first prescription; nonuser entry is dialysis start plus a randomly sampled user delay. Exclude events/censoring before assigned entry. Users have treatment-gap and last-supply censoring rules; weighted Cox analyses include treatment and censoring weights. [reported Methods]
- **Pitfalls:** sampled delays address time alignment but do not prove exchangeability. Differential treatment discontinuation can be informative; the paper acknowledges healthier time on treatment. A null hip-fracture control does not exclude residual confounding. Main Results report 17,875 prior users excluded in sensitivity analysis despite only 6,306 exposed in the final cohort; reconcile the denominator/stage before reproducing that flow. [reported Results; Limitations; inference]
- **Locators:** complete main text; detailed code tables and supplements unread. Separate primary analysis from the incident-user sensitivity analysis.
