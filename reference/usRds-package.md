# usRds: Load, Label and Analyze United States Renal Data System Files

Load, label and analyze files from the United States Renal Data System
(USRDS), the national data system on chronic kidney disease and
end-stage kidney disease in the United States. Users supply USRDS files
they have obtained, in 'SAS', comma-separated values (CSV) or 'Parquet'
format; the package finds them, chooses one file for each file name and
year, and reads them with upper-case column names. Variables and values
can be labelled from the appendices of the USRDS Researcher's Guide.
Medicare claims can be extracted by diagnosis, procedure and provider
specialty codes, and used to date diagnoses, build cohorts, and compute
claim costs with daily proration and medical care inflation adjustment.
